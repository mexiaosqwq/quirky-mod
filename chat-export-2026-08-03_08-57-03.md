两条我之前给错的规则，本版一并推翻：

- **`@`(24) 不该用于胸甲中缝。** 深底上它就是洞。中缝改 `d`(107)：压在 `M`(190) 上仍读成缝，但不穿透。
- **靴子不该有灰色鞋底。** 异色底 = 异物。鞋底改用 `t`(190,140,95)，同色系高光，既定住底缘又不脱离靴身。

另外你的预览底色还是灰的（≈#666）。灰底上 `d`(107) 是暗色，深底上是中亮色，明暗关系整个翻转——contact sheet 底色务必改 `#100010`。

```python
def write_sheet(path, grids, scale=8, bg=(16, 0, 16, 255)):
    """Vertical column at 14px line pitch on the real tooltip background."""
    cols, rows = 16, 14 * len(grids) + 2
    canvas = [bg] * (cols * rows)
    for i, g in enumerate(grids):
        px = render(g)
        for y in range(16):
            for x in range(16):
                p = px[y * 16 + x]
                if p[3] and 0 <= i * 14 + y < rows:
                    canvas[(i * 14 + y) * cols + x] = p
    W, H = cols * scale, rows * scale
    big = [canvas[(y // scale) * cols + (x // scale)]
           for y in range(H) for x in range(W)]
    write_png_size(path, big, W, H)   # write_png 内的 16 换成 W/H
```
