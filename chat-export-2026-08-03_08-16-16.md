## 一、旧版为什么丑（逐图定位）

| 图标 | 根因 | 具体表现 |
|---|---|---|
| 剑 | 护手断裂 | `r7 "MM#"` 与 `r8 "WM#@M##"` 两段没对齐，读成"刃上粘了个灰块"，不成十字护手 |
| 剑 | 刃太瘦 | `WM#@` 里 `@`(24) 在 #100010 底上≈隐形 → 实际只有 2–3px 可见，成"针" |
| 闪电 | 纯线无体量 | 3px 单折 zigzag，没有"闪"的 belly，读成一根歪斜线 |
| 胸甲 | 土豆形 | 无肩、无腰线收分，就是个中间劈了缝的实心块 |
| 靴子 | 积木块 | 直筒+平底，`@` 整行做底缝 → 靴子"浮"在一条灰杠上方，有割裂感 |
| 箭头 | 空心太细 | 2px 开放箭头面积不足，方向清楚但"没分量"，与其它 5 图不齐 |

共性：**形体普遍只有 2–3px，暗部用 `@`/`#` 在深底上塌成隐形，导致所有图标偏瘦、偏碎。** 新版统一加粗主体到 3–4px、暗部改用可见灰阶、并补足轮廓辨识度。

    px = []
    for row in grid:
        row = row.ljust(16, '.')
        assert len(row) == 16, f'row not 16 chars: {row!r}'
        for ch in row:
            px.append(PAL.get(ch, (0, 0, 0, 0)))
    return px

def write_png(path, px):
    def chunk(tag, data):
        c = struct.pack('>I', len(data)) + tag + data
        return c + struct.pack('>I', zlib.crc32(tag + data) & 0xffffffff)
    px_bytes = bytes(v for p in px for v in p)
    raw = b''.join(b'\x00' + px_bytes[i:i + 64] for i in range(0, len(px_bytes), 64))
    png = (b'\x89PNG\r\n\x1a\n'
           + chunk(b'IHDR', struct.pack('>IIBBBBB', 16, 16, 8, 6, 0, 0, 0))
           + chunk(b'IDAT', zlib.compress(raw))
           + chunk(b'IEND', b''))
    with open(path, 'wb') as f:
        f.write(png)
