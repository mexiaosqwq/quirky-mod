# Quirky

一个面向 Minecraft 26.2 的小型 Fabric 模组，提供一系列原版风格的小机制，灵感来自 Quark。模组依赖 Fabric API 与 cloth-config（必需依赖），ModMenu 为可选依赖（推荐，用于游戏内配置）。

## 功能

### 物品与方块

- **云瓶**：用玻璃瓶和幻翼膜合成 `quirky:bottled_cloud`。右键放置一朵临时云，进入后会缓慢下落，持续 10 秒，并且可以被放置方块替换；着火的实体进入云块会被灭火，云块随之消失；手持空玻璃瓶右键云块可以把它收回成云瓶。消耗云瓶时返还玻璃瓶；创造模式不消耗也不返还。
- **保留图腾**：死亡时背包物品集中存入死亡点上方生成的悬浮图腾（非 PVP 击杀、非创造、`keepInventory` 关闭时生效），任何玩家击打（次数可配置，默认 3 次）取回，按原槽位归还；未取回再死则旧图腾破裂散落。消失诅咒物品不保存；经验照常掉落。生成高度可配置（默认死亡点上方 1 格，最高 2 格）。
- **金按钮**：任意木按钮 + 金粒合成。按下保持 **2 红石刻（0.1 秒）** 的短脉冲；金属音效；箭不可触发。
- **铁按钮**：石按钮 + 铁粒合成。按下保持 **100 刻（5 秒）** 的长脉冲；金属音效；箭不可触发。
- **黑曜石压力板**：2 块黑曜石合成。**仅玩家**踩上触发（生物、掉落物不触发），输出满强度信号；硬度与黑曜石一致（50/1200，需正确工具开采），适合做防误触的门禁开关。
- **火把箭**：火把 + 箭合成。基础伤害固定为 1（不受弓拉满加成），命中实体点燃 3 秒；命中可替换方块（如草、空气）时会在落点放置火把；无法放置时箭以掉落物形式落地，可拾取回收。
- **木漏斗**：5 块木板 + 1 个箱子按原版漏斗形状合成。与铁漏斗一样能吸物品、往下方容器吐物品、右键打开，但搬运速度为铁漏斗的四分之一（每 32 tick 移 1 个物品）；红石信号无法锁住它（原版漏斗被激活会锁住）。朝下悬空（下方无容器且为空气）时物品会从漏斗口漏出成掉落物，可作物品管道。也可作燃料，烧 15 秒。

### 机制

- **地图预览提示**：悬停已填充的地图时，显示 71x71 实时预览（含比例与锁定状态），并保留原版羊皮纸边框。
- **右键收割与补种**：右键成熟的小麦、胡萝卜、马铃薯、甜菜根、下界疣或可可豆即可收割，并尽可能补种；也可以右键瓜藤采摘南瓜和西瓜。
- **双开门联动**：打开一扇木门时，相邻的配套木门会一起开关，包括实体触发的开门；铁门和纯红石控制保持原版行为。
- **时钟提示**：时钟显示游戏内天数和时间。
- **背包快速装备**：在容器界面右键可装备物品，直接穿戴，或与已穿戴装备互换；创造模式背包同样可用。
- **副手快速装备**：在容器界面右键盾牌、火把、风弹或烟花火箭，可直接与副手槽互换；与背包快速装备独立。
- **西瓜籽吐出**：生存模式吃完最后一片西瓜时，会吐出一个西瓜籽掉落物，带 40 tick 拾取延迟和音效。
- **自动爬梯**：面对梯子或藤蔓时，抬头自动上升、低头下降；平视时缓慢下滑（不会自动爬升）。脚手架不受影响。
- **死亡电影镜头**：死亡后镜头从贴近尸体处缓缓拉远展示，再进入死亡界面，可配置时长。
- **灵魂光源**：火把/蜡烛放在灵魂沙/灵魂土上时，火焰呈灵魂青色（26.2 灯笼不支持，保持原版）。

### 客户端提示增强（Client QoL）

- **潜影盒预览**：悬停潜影盒时，在提示中显示盒内物品网格；空盒显示“空”状态。
- **食物信息提示**：食物提示中显示饥饿值与饱和度（带图标），并按需补充食用时长、可满饥食用、状态效果（含概率）、清除/移除效果与随机传送等条件信息。
- **属性图标提示**：以紧凑横排图标显示攻击伤害（含附魔加成）、攻速、护甲与韧性，属性过多时自动换行；按住 Shift 可查看原版提示。
- **使用量挂件**：拾取/消耗物品时在快捷栏上方滑出数量；护甲掉耐久时滑出耐久条，停留时长与动画时长可配置。

### 配置

各机制可在 ModMenu → Quirky 配置（或 `config/quirky.json5`）独立禁用，关掉即恢复原版行为。图腾参数（击打次数、生成高度、音效、粒子、模型浮动/旋转/摇摆）与客户端 QoL 参数（挂件时长、死亡镜头时长等）均可调。专用服务器：服主编辑服务器 `config/quirky.json5` 后执行 `/quirky reload` 热重载（权限等级 2）。

## 运行要求

- Minecraft 26.2
- Fabric Loader 0.19.3+
- Fabric API 0.155.2+26.2
- Cloth Config API 26.2.155+
- Java 25+

## 安装

1. 为 Minecraft 26.2 安装 [Fabric Loader](https://fabricmc.net/use/)。
2. 下载并安装**前置依赖**（放入 `.minecraft/mods/`）：
   - [Fabric API](https://modrinth.com/mod/fabric-api)（必需）
   - [Cloth Config API](https://modrinth.com/mod/cloth-config)（必需）
   - [ModMenu](https://modrinth.com/mod/modmenu)（可选，推荐，用于游戏内配置界面）
3. 下载或自行构建 `quirky-1.0.0.jar`，一并放入 `.minecraft/mods/`。
4. 使用 Fabric 配置启动游戏。

> 缺少必需前置时游戏会拒绝加载本模组并提示缺失依赖；ModMenu 仅影响能否在游戏内打开配置界面，配置文件仍可直接编辑 `config/quirky.json5`。

## 构建

需要 JDK 25，在仓库根目录运行：

```bash
./gradlew build --no-daemon --console=plain
```

单元测试使用 `./gradlew test`；客户端视觉效果仍需要在桌面客户端手动验证。构建产物位于 `build/libs/quirky-1.0.0.jar`。

## 范围

- **配置**：已接入 Cloth Config API——机制开关（行为类机制关掉即恢复原版行为）+ 图腾手感参数（击打次数/生成高度/音效/粒子/渲染尺寸/浮动/旋转/摇摆）+ 客户端 QoL 参数，游戏内可调。单机/局域网在 ModMenu 里打开 Quirky 配置界面；专用服务器由服主编辑 `config/quirky.json5` 后执行 `/quirky reload` 热重载。ModMenu 为可选依赖，cloth-config 为必需依赖。
- 红石直控门联动有意不实现。
- 客户端行为需要桌面客户端手动验证；服务端机制通过构建和专用服务器冒烟测试验证。
