# Quirky

一个面向 Minecraft 26.2 的小型 Fabric 模组，提供一系列原版风格的小机制，灵感来自 Quark。依赖 Fabric API 与 cloth-config（必需），ModMenu 可选（推荐，用于游戏内配置）。

## 功能

### 物品与方块

- **云瓶**：玻璃瓶 + 幻翼膜合成，右键放云（持续 10 秒），手持空瓶可收回；创造模式不消耗。
- **保留图腾**：死亡时背包存入死亡点上方悬浮图腾，击打取回（次数可配置）；未取回再死则旧图腾散落。
- **金按钮**：任意木按钮 + 金粒，2 红石刻短脉冲；金属音效；箭不可触发。
- **铁按钮**：石按钮 + 铁粒，100 刻长脉冲；金属音效；箭不可触发。
- **黑曜石压力板**：仅玩家踩踏触发，输出满强度信号；硬度与黑曜石一致。
- **火把箭**：火把 + 箭合成，命中点燃 3 秒；可替换方块处落点放火把，否则掉落回收。
- **回旋镖**：2 木棍 + 羽毛 V 形合成，蓄力投掷（力度定初速/射程），可穿透命中多个目标并远程激活机关；沿弧线自动回手，玩家在投掷点附近则追踪接住，跑远则飞回投掷点掉落；耐久 250。
- **木漏斗**：5 木板 + 箱子，1/4 速度搬运，红石锁不住；悬空时物品漏出成掉落物。
- **绳 / 挂灯绳段**：泰拉瑞亚式沿墙/悬挂铺绳，可攀爬并缓滑防摔；手持灯笼可替换为挂灯段（亮度 15）；支撑失效时连锁掉落。
- **箭袋**：3 皮革 + 线合成，储存箭与烟花火箭，弓/弩自动抽取；可染色。
- **末影袋**：皮革 + 末影珍珠，便携末影箱。
- **宠物哨**：吹哨召唤半径内宠物寻路走来（远距离直接传送），潜行 + 右键切换坐定/站起。
- **播种袋**：右键耕地播种，物品栏内光标点击装取种子。
- **鱼饵**：扔到水面形成诱鱼区，区内浮漂咬钩更快。
- **鹦鹉蛋**：蛋 + 羽毛合成，投掷后 50% 孵出鹦鹉（丛林 75%），1/32 概率双胞胎。

### 机制

- **箭响**：箭命中发声——生物铃响、金属盔甲铿锵、盾牌格挡无声。
- **起床缓落**：起床获得短暂缓落（深度睡眠全额，被打断仅 1/3）。
- **染色营火烟**：营火加入染料/荧石/火药可染色或加浓烟。
- **地图预览提示**：悬停已填充地图显示 71x71 实时预览（保留原版羊皮纸边框，Shift 查看）。
- **右键收割与补种**：右键成熟作物收割并自动补种；可采摘瓜藤。
- **双开门联动**：木门联动开关，铁门保持原版。
- **时钟提示**：时钟显示天数与时间（Shift 查看）。
- **背包快速装备**：容器界面右键直接穿戴或与已穿戴互换；副手槽同理（盾牌/火把/风弹/烟花）。
- **西瓜籽吐出**：吃完最后一片西瓜吐出籽掉落物（带拾取延迟和音效）。
- **自动爬梯**：面对梯子/藤蔓抬头上升、低头下降，平视缓滑；脚手架不受影响。
- **死亡电影镜头**：死亡后镜头缓缓拉远再进死亡界面，时长可配置。
- **灵魂光源**：火把/蜡烛放灵魂沙/土上呈灵魂青色火焰。

### 客户端提示增强（Client QoL）

- **潜影盒预览**：悬停显示盒内物品网格（Shift 查看）。
- **食物信息提示**：显示饥饿值、饱和度与食用条件等（带图标）。
- **属性图标提示**：横排图标显示攻击/攻速/护甲/韧性（Shift 看原版）。
- **高级 Tooltip 模式**：长描述默认隐藏，按住 Shift 显示，并附提示行。
- **使用量挂件**：拾取/消耗物品与护甲掉耐久时在快捷栏上方滑出提示。

### 配置

各机制恒开（无开关），数值参数在 ModMenu → Quirky（或 `config/quirky.json5`）中可调：物品参数（箭袋容量、绳延伸上限、回旋镖射程/伤害、播种袋范围、鱼饵时长/半径、口哨半径等）、图腾手感参数、客户端 QoL 参数。专用服务器改配置后执行 `/quirky reload` 热重载（权限等级 2）。

## 运行要求

- Minecraft 26.2 · Fabric Loader 0.19.3+ · Fabric API 0.155.2+26.2 · Cloth Config API 26.2.155+ · Java 25+

## 安装

1. 为 Minecraft 26.2 安装 Fabric Loader。
2. 将 Fabric API、Cloth Config API 放入 `mods/`（必需），ModMenu 可选。
3. 将 `quirky-1.0.0.jar` 一并放入 `mods/`。

## 构建

需要 JDK 25，在仓库根目录运行：

```bash
./gradlew build --no-daemon --console=plain
```

单元测试 `./gradlew test`；客户端视觉效果需桌面客户端手动验证。产物在 `build/libs/quirky-1.0.0.jar`。

## 范围

- 机制恒开，配置仅含数值参数；红石直控门联动有意不实现。
- 客户端行为需桌面客户端手动验证；服务端机制通过构建与专用服务器冒烟测试验证。
