# 客户端机制桌面端手动验证清单

> Termux 环境无 GUI，以下视觉/手感类机制以 build + 单测（逻辑部分）+ 代码审查验证；
> 发布前必须在桌面客户端按本清单逐项手动验收（spec 2026-08-02-quirky-client-qol-design.md 第 8 节）。

## Tooltip 三件（Task 2/3/4）
- [ ] 悬停任意潜影盒：出现 3x9 内容网格，物品图标 + 数量正确，空格留空
- [ ] 悬停面包/牛排/金苹果：出现鸡腿图标 + 数值 + 饱和度图标 + 数值
- [ ] 悬停钻石剑：横排单行显示攻击伤害 7、攻速 1.6；锋利 V 显示 10（7+3.0）
- [ ] 悬停钻石胸甲：横排单行护甲 8 + 韧性 2；未按 Shift 时无原版属性文本段；按住 Shift 时横条隐藏、原版文本行显示
- [ ] 非食物/无属性物品 tooltip 无变化

## 使用量挂件（Task 5）
- [ ] 拾取 3 个圆石：快捷栏左侧滑出圆石图标 + 总数
- [ ] 吃面包：左侧滑出剩余面包数
- [ ] 被攻击掉耐久：右侧滑出横排 4 条护甲耐久条；耐久停止约 3 秒后收回
- [ ] 动画为自下而上 ease-out（20px 上滑），不突兀
- [ ] 背包整理（多槽同帧变化）不触发挂件

## 死亡电影镜头（Task 6）
- [ ] 死亡后先播放 ~2.5 秒环绕运镜（镜头围绕死亡点转一圈并拉远），再进死亡界面
- [ ] 镜头期间鼠标视角不干扰镜头；Esc 可跳过
- [ ] 创造/旁观模式不触发；掉线/切换维度无残留

## 灵魂光源（Task 7）
- [ ] 火把插在灵魂沙上：整体呈灵魂青色（与灵魂火把一致）
- [ ] 灯笼放灵魂土上：青色；墙上火把同样生效
- [ ] 蜡烛（含彩色）放灵魂方块上：火焰呈青色
- [ ] 火焰粒子（火把/蜡烛）在灵魂方块上呈青色
- [ ] 敲掉/移走灵魂方块后恢复橙色
- [ ] 熔炉/其他光源方块不受影响

## 交互 tweak（Task 9/10/11）
- [ ] 创造模式中键可拾取 100 格外方块；生存 12 格
- [ ] 爬梯子/藤蔓抬头自动上升、低头下降、平视缓慢下滑不爬；按 W/S 手动爬正常；脚手架自由走动/空格升/Shift 降不受干预
- [ ] 右键背包盾牌 ↔ 副手互换；右键火把装入副手；副手有物品时互换
- [ ] 非盾牌/火把物品右键仍走主手装备逻辑

## 新方块/物品（Task 12-15）
- [ ] 金按钮：点击 0.1s 后熄灭（2 刻）；铁按钮：5 秒长亮
- [ ] 金/铁按钮配方（木按钮+金粒 / 石按钮+铁粒）可合成
- [ ] 黑曜石压力板：玩家踩上亮、牛/掉落物踩上不亮
- [ ] 火把箭：弓/发射器可射出；射中僵尸点燃；射中泥土放置火把；无法放置处掉落物品
- [ ] 木漏斗：4 倍慢传输；红石信号下不停止；可作熔炉燃料（15s）；破坏掉落内容物
- [ ] 新方块/物品在创造页签（红石/战斗）中出现，模型非紫黑棋盘格（items/ 双文件核对）
