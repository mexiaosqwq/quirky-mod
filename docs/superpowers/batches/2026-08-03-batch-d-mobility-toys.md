# 批 D — 机动与玩具

> 状态：**待设计**。开发时每个机制走完整流程：brainstorming 细节问答 → `docs/superpowers/specs/` 设计文档 → `docs/superpowers/plans/` 实现计划 → 实现+两阶段审查。

## 机制清单

| 机制 | 类型 | 一句话描述 |
|---|---|---|
| 绳捆 | 机动工具 | 可向下方投掷放置的攀爬绳，占一格、可爬、能从上方一路往下铺（参考 Quark ropes） |
| 回旋镖 | 机动/战斗玩具 | 投掷后飞回手中的回旋镖（参考 Quark boomerang），可拾取物品/轻伤害，需调好飞行手感 |

## 设计约束

- 实用、不影响平衡、轻量（用户定调）；回旋镖伤害要低，定位是玩具/拾取工具而非武器
- 绳捆需接入攀爬判定（参考项目自动爬梯经验：`#minecraft:climbable` tag 路径）
- 回旋镖涉及自定义实体：渲染、飞行轨迹、回收路径唯一（防双回收，参考火把箭教训）
- 每个机制必须带手感细节：音效、粒子、挥动/反馈
- 遵循项目 AGENTS.md：26.2 API 实测、mixin 运行时审计清单、新物品资源双文件

## 独立性

两项互不依赖；与批 A/B/C 无依赖。回旋镖实现复杂度最高，建议放批内最后。
