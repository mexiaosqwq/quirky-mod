# Quirky v1.1 机制批次路线图

> 2026-08-03 与用户敲定的 11 项新机制清单，按主题分 4 批。每批一个独立清单文件，可开独立工作区（worktree）并行推进。

## 定调

**实用、不影响平衡、轻量**；每个机制必须有手感细节（音效/粒子/反馈）；规格→计划→实现流程不变。

合成板、路标罗盘、天气钟、快降梯、音叉、盾牌猛击、矿车挂钩、起床保护、桶装史莱姆、泥瓦铲、磁石指环。

## 工作流程

1. 每批开发前，对该批机制逐个做 brainstorming 细节问答（一次一个机制）
2. 设计文档写 `docs/superpowers/specs/`，实现计划写 `docs/superpowers/plans/`
3. 并行开发时每批用独立 worktree，任务文本限定可修改文件范围（见项目 AGENTS.md）
4. 完成后更新本表状态列
