# 批 C — 收纳与伙伴

> 状态：**待设计**。开发时每个机制走完整流程：brainstorming 细节问答 → `docs/superpowers/specs/` 设计文档 → `docs/superpowers/plans/` 实现计划 → 实现+两阶段审查。

## 机制清单

| 机制 | 类型 | 一句话描述 |
|---|---|---|
| 箭袋 | 收纳容器 | 存箭容器（1 个箭袋装一组箭），右键装填/取用，省背包格子，与已有火把箭搭配（注意弓箭 tag 兼容） |
| 末影袋 | 收纳容器 | 随身携带的末影箱入口（物品形态，右键打开末影箱界面） |
| 宠物口哨 | 伙伴玩具 | 吹响口哨，范围内的狗/猫/鹦鹉跑/飞过来（口哨声+爱心粒子） |

## 设计约束

- 实用、不影响平衡、轻量（用户定调）
- 容器类机制必须处理：满背包、堆叠、死亡掉落、创造/生存差异（参考项目"主动推演细节场景"纪律）
- 每个机制必须带手感细节：音效、粒子、挥动/反馈
- 遵循项目 AGENTS.md：26.2 API 实测、mixin 运行时审计清单、新物品资源双文件

## 独立性

三项互不依赖；与批 A/B/D 无依赖。
