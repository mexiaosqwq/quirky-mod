# 批 A — 轻量手感与小点缀

> 状态：**待设计**。开发时每个机制走完整流程：brainstorming 细节问答 → `docs/superpowers/specs/` 设计文档 → `docs/superpowers/plans/` 实现计划 → 实现+两阶段审查。

## 机制清单

| 机制 | 类型 | 一句话描述 |
|---|---|---|
| 弓箭命中"叮"声 | 手感音效 | 箭矢命中实体时播放清脆的"叮"反馈音 |
| 营火染色烟 | 粒子玩具 | 把染料丢进营火，烟柱变色 |
| 鹦鹉蛋 | 投掷玩具 | 可投掷的彩色蛋，落地孵出小鹦鹉（碎壳粒子+叫声） |
| 安眠规则 | 多人生存 | 配置比例的入睡玩家即可跳过夜晚；**用户无法多人实测**，核心比例判断抽纯逻辑单测，游戏内尽量复用原版入睡计数 API，默认 100% 等同原版行为 |

## 设计约束

- 实用、不影响平衡、轻量（用户定调）
- 每个机制必须带手感细节：音效、粒子、挥动/反馈，"逻辑能跑"不算完成
- 遵循项目 AGENTS.md：26.2 API 实测、mixin 运行时审计清单、新物品资源双文件（items/ + models/item/）

## 独立性

四项互不依赖，可并行开发；与批 B/C/D 无依赖。
