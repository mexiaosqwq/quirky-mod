# 批 B — 田园渔猎

> 状态：**待设计**。开发时每个机制走完整流程：brainstorming 细节问答 → `docs/superpowers/specs/` 设计文档 → `docs/superpowers/plans/` 实现计划 → 实现+两阶段审查。

## 机制清单

| 机制 | 类型 | 一句话描述 |
|---|---|---|
| 播种袋 | 田园工具 | 手持右键耕地，从背包批量播撒种子（撒种音效+绿色粒子），与已有收割补种机制形成种田闭环 |
| 鱼饵球 | 钓鱼玩法 | 扔到水面化开，鱼群聚拢、浮漂咬钩更频繁（雾化粒子） |

## 设计约束

- 实用、不影响平衡、轻量（用户定调）；鱼饵球需明确增益幅度，避免钓鱼完全自动化
- 每个机制必须带手感细节：音效、粒子、挥动/反馈，"逻辑能跑"不算完成
- 播种袋注意与现有 `harvest` 机制的交互（收割后立即补种场景）
- 遵循项目 AGENTS.md：26.2 API 实测、mixin 运行时审计清单、新物品资源双文件

## 独立性

两项互不依赖；与批 A/C/D 无依赖。
