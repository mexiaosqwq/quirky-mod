# 副手装备与物品提示优化设计

## 状态

- 设计已获用户确认。
- 实现工作区：`.worktrees/equip-tooltip-options`
- 目标分支：`feat/equip-tooltip-options`

## 背景

Quirky 当前同时提供 `equipSwap`（快速装备）和 `offhandSwap`（副手快速装备）两个配置项。两者应继续保持独立，但在配置界面中属于同一类装备切换功能。副手快速装备目前只覆盖盾牌和火把；客户端拦截与服务端总开关之间也存在耦合，可能导致关闭一个功能后出现点击被拦截但服务端拒绝的无反馈行为。

当前物品提示已经包含地图、潜影盒、食物、属性和时钟等增强，但食物提示只显示营养值和饱和度，其他有实际价值的食用行为没有被整理出来；属性横条在内容较多时可能过长，潜影盒空状态和地图元信息也有进一步改善空间。

## 目标

1. 保留 `equipSwap` 与 `offhandSwap` 两个独立配置项，并让它们在同一个配置分组中相邻显示。
2. 让副手快速装备支持盾牌、火把、风弹和烟花火箭的所有物品变体。
3. 使两个配置项在客户端拦截和服务端执行路径上真正独立，关闭功能时恢复原版容器点击行为。
4. 把食物提示升级为“基础信息 + 仅在存在时显示的条件信息”，提供食用效果、概率、时长和特殊行为等有用信息，同时避免重复和空行。
5. 改善属性、潜影盒和地图提示的可读性与信息层级，不引入额外的提示详细程度配置。
6. 保持服务端权威、物品替换无损、搜索索引可用、tooltip 几何边界正确，并通过构建、测试和客户端手动验证。

## 非目标

- 不重做整个 Minecraft 通用 tooltip 系统。
- 不新增“简洁/详细/专家”等新的配置开关。
- 不重复绘制原版已经负责展示的烟花组件、疑似炖菜效果文本或其他组件信息。
- 不改变盔甲交换、诅咒阻止卸甲、创造模式物品栏映射等既有业务规则。
- 不改变地图、潜影盒、属性和时钟功能的开关名称或存档键。

## 配置与副手装备

### 配置分组

- `equipSwap` 和 `offhandSwap` 均使用现有的 `toggles` 分类。
- 配置类中的两个字段相邻排列，配置界面也应连续显示。
- 保留已有字段名，避免旧配置文件迁移问题。
- 中英文名称和说明必须准确反映实际行为。

`equipSwap` 控制盔甲及带 `EQUIPPABLE` 组件的普通快速装备；`offhandSwap` 控制 Quirky 专属的副手物品集合。

### 开关独立性

| `equipSwap` | `offhandSwap` | 允许的快速装备行为 |
|---|---|---|
| 开 | 开 | 普通可装备物品 + 副手专属物品 |
| 关 | 开 | 仅副手专属物品 |
| 开 | 关 | 普通可装备物品；盾牌可按既有 `EQUIPPABLE` 路径处理 |
| 关 | 关 | 不拦截右键，交还原版容器行为 |

客户端只有在对应功能开启、来源槽位有效且没有携带物品时才取消原版鼠标事件并发送 payload。服务端不能依赖单一总开关，而必须根据来源物品和目标路径再次判断对应开关。

### 副手物品

`OffhandSwapItems` 的专属集合为：

- `Items.SHIELD`
- `Items.TORCH`
- `Items.WIND_CHARGE`
- `Items.FIREWORK_ROCKET`

按物品类型判断，不限制堆叠数量、烟花飞行时间、烟花爆炸组件或其他合法物品组件。

### 交换与安全语义

继续使用现有装备交换路径，并覆盖以下场景：

- 副手为空：来源堆叠移入副手，来源槽位清空或减少。
- 副手已有物品：副手物品回到来源槽位，不能吞物或复制。
- 来源槽位是创造模式物品栏其他标签页映射出的有效玩家库存槽位：允许处理。
- 来源槽位是假槽位、容器 ID 不匹配、携带物品非空、来源为空：拒绝。
- 普通装备继续校验 `EQUIPPABLE`、目标装备槽和 `isEquippableInSlot`。
- 受 `PREVENT_ARMOR_CHANGE` 保护的现有装备继续阻止非创造模式交换。
- 服务端是最终权威，客户端不能仅凭本地开关改变结果。
- 功能关闭时，客户端不应先拦截再等待服务端拒绝；必须直接放行原版点击。

## 物品提示信息架构

### 统一原则

- 普通物品只显示高价值、稳定的信息。
- 只有数据实际存在或偏离默认行为时才增加额外行。
- 数值、图标、行高和间距复用现有 tooltip 行度量，避免不同组件视觉漂移。
- 动态组件的 `getWidth` 和 `getHeight` 必须与实际绘制内容一致。
- 自定义提示尊重 `TooltipDisplay` 的隐藏语义，不在物品明确隐藏信息时额外显示。
- 内容优先使用原版翻译、效果名称和原版图标，不创建重复的效果命名体系。

### 食物提示

#### 基础行

所有具有 `FOOD` 数据组件的物品显示：

- 营养值（饥饿值）
- 实际饱和度

基础行保留图标与紧凑数字形式，因为原版 tooltip 不直接展示这两个关键数值。

#### 条件信息

仅在存在时显示：

- `canAlwaysEat`：可在满饥饿值时食用。
- 非默认消耗时间：显示食用或饮用方式及时间；默认消耗时间不显示。
- 非默认使用动画：例如饮用型食物使用“饮用”文案，而不是一律写“食用”。

#### 食用效果

从 `CONSUMABLE` 的已知原版效果类型生成紧凑效果行：

- 应用状态效果：效果名称、等级、持续时间；概率低于 100% 时追加概率。
- 移除指定状态效果：显示被移除的效果名称。
- 清除全部状态效果：显示清除全部状态效果。
- 随机传送：显示随机传送行为。
- 仅播放声音等不影响玩家状态的内部效果不作为 tooltip 内容，避免把实现细节暴露为噪音。

效果行使用原版状态效果图标和名称，并区分有益/有害效果的颜色层级。多条效果垂直排列，不强行塞成超长单行。

疑似炖菜的 `SUSPICIOUS_STEW_EFFECTS` 继续由原版专用 tooltip 路径处理，Quirky 不再绘制第二份相同效果，避免创造模式重复显示。

#### 食物提示边界

- 只有基础信息的普通食物保持单行紧凑布局。
- 没有可识别的附加效果时不显示“效果：无”。
- 消耗组件缺失时仍可显示基础 FOOD 信息，不因自定义物品组件不完整而崩溃。
- 小数使用稳定的 `Locale.ROOT` 格式化。
- Tooltip 隐藏或 `FOOD` 组件被隐藏时，不显示 Quirky 食物图片组件。

### 属性提示

- 保留当前紧凑图标横条和 Shift 查看原版属性文本的互斥行为。
- 属性项目较多或文本较长时按紧凑宽度自动换行，而不是生成横跨屏幕的长条。
- 每个支持的属性最多显示一次，继续省略不存在或被隐藏的修饰符。
- 原版文本隐藏逻辑继续保留 `player == null` 早退，保证创造/配方搜索索引仍然可搜索。
- 换行后的高度、图标垂直居中和 Shift 隐藏状态必须同步计算。

### 潜影盒提示

- 保留 9×3 真实槽位布局，因为槽位位置有实际意义。
- 空潜影盒显示明确的空状态提示，避免大块空网格看起来像渲染故障。
- 非空盒继续绘制物品、堆叠数量、盒子颜色背景和边框。
- 不额外生成一份文本物品清单，避免和网格重复。

### 地图提示

- 保留现有地图羊皮纸边框和地图内容对齐。
- 有地图数据时在预览下方增加轻量元信息：地图比例，以及锁定状态（仅在锁定时显示）。
- 无地图数据时不绘制错误的元信息。
- 新增元信息后重新计算组件边界，所有绘制必须位于 `getWidth`/`getHeight` 报告范围内。

### 时钟与原版组件

- 时钟继续显示天数和时间，统一中英文文本和格式，不增加低价值字段。
- 烟花、药水、附魔、疑似炖菜等已有原版数据组件继续使用原版详情；Quirky 不重复复制这些内容。

## 数据流与组件边界

1. 普通/服务端共享代码从 `ItemStack` 的数据组件提取安全的 tooltip 数据。
2. `FoodTooltipComponent` 携带食品基础值、可选消耗信息和可渲染的效果预览数据。
3. 客户端 callback 将共享 tooltip 组件转换为客户端绘制组件。
4. 客户端绘制组件只负责几何、图标和文本，不在渲染阶段执行游戏逻辑。
5. 副手物品判定保持在服务端与客户端共享的轻量 helper 中，避免客户端依赖服务端入口类。
6. 不新增网络 payload；装备交换继续使用现有 payload，并由服务端重新读取来源槽位的真实物品。

## 测试与验收

### 单元测试

- 副手 helper 接受盾牌、火把、风弹和烟花火箭，拒绝无关物品。
- 四种配置组合分别验证普通装备和副手专属装备的允许/拒绝行为。
- 四种副手物品分别验证空副手放入、已有副手物品互换和来源堆叠保持。
- 客户端在对应开关关闭时不拦截点击；创造模式各标签页槽位映射保持有效。
- 食物基础行、满饥饿可食用标记、非默认消耗时间、状态效果、概率、特殊效果和空效果列表覆盖测试。
- 食物小数格式化不受默认 Locale 影响。
- 属性多行宽高和 Shift 隐藏行为覆盖测试。
- 空/非空潜影盒提示、地图元信息边界和无地图数据 fallback 覆盖测试。
- 配置默认值和翻译键保持一致。

### 客户端手动验证

- 配置界面中两个开关出现在同一分组且相邻。
- 分别关闭两个开关，确认另一个功能仍可用，关闭时原版右键行为恢复。
- 盾牌、火把、风弹、普通烟花火箭和带不同飞行时间/爆炸组件的烟花火箭均可互换。
- 满副手、满来源堆叠、创造模式不同标签页、携带物品和假槽位场景无丢失/复制。
- 普通食物、金苹果、带概率负面效果的食物、蜂蜜瓶、紫颂果和自定义带效果食物的提示内容正确。
- Shift 属性查看、空潜影盒、彩色潜影盒、地图比例/锁定信息和时钟提示可读且不溢出边界。
- 创造物品搜索仍能搜索属性文本。
- 交付前逐项执行 Quirky 26.2 Mixin/API 运行时审计，不能仅以编译通过代替运行时验证。
