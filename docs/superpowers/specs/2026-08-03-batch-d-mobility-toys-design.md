# 批 D 设计文档 — 机动与玩具

日期：2026-08-03
状态：待用户审阅
定调：实用、不影响平衡、轻量；每个机制必须有音效/粒子/反馈等手感细节。

## 1. 绳捆（Rope）

### 1.1 定位

可从上往下铺的攀爬绳：站在高处往脚下放绳，一路垂到地面，爬绳上下。探洞、下矿、树屋的轻量机动工具。参考 Quark ropes，但按 Quirky"简单优先"裁剪：**不做投掷铺设弹道，只保留"向下延伸"核心体验**。

### 1.2 方块行为

- 新方块 `quirky:rope`：
  - **无碰撞箱**（可穿过），**可攀爬**：加入 `#minecraft:climbable` block tag（玩家贴绳按住前进即可爬，机制与藤蔓一致——项目自动爬梯已验证该 tag 路径）。
  - 视觉：一格高的麻绳段，细绳居中垂直贯穿（贴图：绳结纹理；模型：cross 型或细柱型，计划阶段择一，预览确认后落地）。
  - 光照透明、不阻挡视线，可含水（waterlogged 属性，水流中照常垂挂）。
- **支撑规则**：绳必须悬挂在"完整固体方块底部"、**栅栏/墙/地狱栅栏顶部**（常见挂点，探险时随处可挂）或"另一段绳"之下；失去支撑时**自下而上连锁掉落为物品**（一段段掉，带掉落音效——手感细节）。
- **挂灯照井（有机扩展）**：手持灯笼对绳段右键 → 该段变为"挂灯绳段"（新方块 `quirky:rope_lantern`，亮度 15），消耗 1 个灯笼；破坏时绳与灯笼双双掉落回收。边爬绳边照亮矿井，不用再一手爬绳一手插火把。
- **天然防摔（climbable tag 白嫖福利）**：坠落中撞上绳柱会自动重置摔落高度（原版攀爬物语义）——绳兼作应急安全绳，铺绳下井摔了也不疼（计划阶段手动实测确认）。
- **放置规则**：
  - 对固体方块底面右键 → 在其下方放一段绳。
  - **对已有绳段右键（手持绳）** → 在其正下方延伸一段（下方为空气时）；这是"一路往下铺"的主操作。
  - **潜行+对绳段右键** → 一次性把绳铺到最近的落地处或耗尽手持数量（上限 32 段/次，防手滑铺穿世界底）。
- **破坏**：打哪段掉哪段；上方的绳若因此失去支撑则连锁掉落。

### 1.3 音效与粒子

| 事件 | 反馈 |
|---|---|
| 放置/延伸 | `SoundEvents.WOOL_PLACE` 类软质音效（项目 BottledCloudItem 已验证可用；音量 0.6，音高随延伸次数轻微递降，"一段段放绳"的节奏感）+ 少量绳纤维粒子（"抖开"的细节） |
| 连锁掉落 | 每段 `SoundEvents.WOOL_BREAK`（音量 0.4）+ 少量线状粒子（`ITEM` 粒子用线物品） |
| 攀爬 | 原版藤蔓/梯子攀爬音效天然生效（climbable tag 附带），不额外加 |
| 批量铺绳 | 快速连续的放置音（每段间隔 1 tick 播放，形成"唰——"的下滑声） |

### 1.4 配方

- 线×3（竖列）→ 绳×3。线易得（蜘蛛/羊毛），符合消耗品定位。

### 1.5 边界场景清单

| 场景 | 行为 |
|---|---|
| 延伸时下方是方块/水 | 水是允许延伸的（绳可含水）；固体方块则停止 |
| 铺绳路径中有半砖/梯子等 | 撞到任何非空气非水方块停止 |
| 支撑方块被活塞推走 | neighbor update 触发支撑检查 → 连锁掉落 |
| 挂在栅栏/墙顶部 | 合法挂点；挂点方块被破坏同样触发连锁掉落 |
| 绳上挂着玩家时被打断 | 玩家自然坠落（无碰撞箱，无特殊处理） |
| 创造模式批量铺 | 不消耗数量，但仍受 32 段/次上限 |
| 两个绳柱相邻 | 互不影响，各自独立支撑链 |
| 世界底部（y=-64） | 铺到最低层停止 |

### 1.6 配置

- `ropeEnabled`（bool，默认 true）
- `ropeMaxExtendPerUse`（int，1-64，默认 32）

### 1.7 实现要点与风险

- 新方块 + BlockItem + tag 文件（`data/minecraft/tags/block/climbable.json` 追加 `quirky:rope` 与 `quirky:rope_lantern`——注意是**合并**进该 tag 的新文件，不是覆盖；数据包 namespace 用 `minecraft` tag 路径加入自有方块是标准做法）。
- `rope_lantern` 是第二个方块（绳+灯笼模型，光照 15），资源走方块清单；挂灯交互 = 右键时方块替换（保留 waterlogged 状态）。
- 连锁掉落逻辑抽纯函数（输入：世界列快照；输出：应掉落的段列表），单测覆盖。
- 风险点：
  - `climbable` tag 在单测环境无数据包数据（项目已验证教训）——攀爬行为只能桌面客户端手动验证。
  - 支撑检查时机：`neighborChanged` + 放置后 tick 双保险。
- 贴图/模型先示意稿后落地。

### 1.8 验证

- 单测：支撑判定、连锁掉落段计算、批量铺设停止条件。
- 手动：桌面客户端放置/延伸/批量铺/攀爬/打断连锁/含水/挂灯照明/坠落抓绳防摔。

## 2. 回旋镖（Boomerang）

### 2.1 定位

投掷后飞回手中的玩具：飞行路径上**拾取地面物品**带给玩家（主要用途），对触碰生物造成轻微伤害+击退（次要，玩具级），撞方块时有小概率打碎普通方块（彩蛋级破坏力）。参考 Quark boomerang，伤害压到玩具水平，定位是拾取工具而非武器。

### 2.2 行为

- 新物品 `quirky:boomerang`：堆叠 1，耐久 **250**（每次完整飞行消耗 1 点），可被铁砧用木材修复。
- **投掷**：主手右键 → 生成 `quirky:boomerang` 实体，沿视线方向飞出：
  - 出手速度 1.0，**无重力**，飞行路径带轻微右偏弧线（回旋镖特征，偏移量小，约每格 0.03 弧度）。
  - 最大飞行距离 **12 格**（约 1.2 秒）后进入返程。
  - 飞行中旋转（客户端模型绕轴自转，每秒约 4 圈）。
- **返程**：达到最大距离或撞到方块后掉头，沿曲线飞回投掷者当前位置（追踪活玩家）：
  - 回到投掷者 1 格内 → 收回：若投掷者手/背包有空位则入包（优先原手持槽），否则掉落在玩家脚下。
  - 投掷者已死亡/离线 → 在实体当前位置掉落为物品。
- **拾取**：飞行实体触碰地面物品实体（0.5 格内）时将其吸收（记入实体 NBT），返航回收时一次性进玩家包（满则掉落）。吸收播放拾取音效。
- **伤害**：触碰生物造成 **2 点（1 心）伤害** + 小击退（0.3），每个生物每次飞行只判定一次（防持续刮擦连击）；对投掷者本人无伤害（返程穿过自己不受击）。
- **远程激活（有机扩展）**：飞行中撞上钟、木按钮、目标块、钟乳石等可被弹射物触发的方块时，调用原版 `block.onProjectileHit` 语义激活它们——隔空敲村里的钟、打按钮开门、触发红石机关，解谜/整活两用。
- **撞碎方块**（彩蛋能力）：撞到方块时按 **5% 概率**尝试打碎：
  - **可碎条件**（全部满足）：方块破坏速度 ≥ 0（非不可破坏）；不在免疫 tag `#quirky:boomerang_unbreakable` 内；投掷者非冒险模式。
  - **秒杀类方块（破坏速度 = 0）必碎**：树叶、高草、花、火把、作物这类一碰就掉的东西不参与 5% 摇骰，撞到就碎——回旋镖因此兼职"开路器"，飞过树林自动清出一条视野。
  - **免疫 tag 默认内容**（数据包可扩展）：基岩、黑曜石、哭泣的黑曜石、远古残骸、下界合金块、重生锚——都是"硬度怪物"或功能性方块，防误拆关键建筑。
  - **打碎成功**：服务端 `destroyBlock` 正常掉落（受 `BLOCK_DROPS` 游戏规则管辖，与原版破坏行为一致，不做特判），播放该方块自身破碎音效与粒子；回旋镖**穿透继续飞**（不反弹，打击感）。
  - **未触发/不可碎**：照常反弹进入返程（原行为）。
  - 去程与返程撞到方块都按同一规则判定；打碎方块不额外消耗耐久。
- 实体免疫火焰/箭矢等伤害，存在上限 10 秒兜底自毁（掉落物品）。

### 2.3 音效与粒子

| 事件 | 反馈 |
|---|---|
| 投掷 | `SoundEvents.ARROW_SHOOT`（已验证）音高 0.8，更"呼"的挥出感 |
| 飞行中 | 低音量嗡鸣循环？——**不做循环音**（容易吵），只保留投掷/命中/回收三类瞬时音效 |
| 命中生物 | `SoundEvents.PLAYER_ATTACK_WEAK_SWEEP`（音量 0.5）+ 原版伤害粒子 |
| 撞到方块 | 未碎：撞击方块自身的 `getSoundType().getHitSound()`（项目 HarvestFx 同款用法，更自然）；打碎：`getSoundType().getBreakSound()` + 原版破坏粒子 |
| 吸收物品 | `SoundEvents.ITEM_PICKUP`（已验证；音量 0.5） |
| 回收到手 | `SoundEvents.ARMOR_EQUIP_GENERIC`（已验证；音量 0.5） |

### 2.4 配方与贴图/模型

- 合成：木棍×2 + 羽毛×1（形状合成，V 型摆放），廉价玩具。
- 物品贴图：木质 V 型回旋镖（先示意稿后落地）；实体用同款贴图做简单平面模型（`builtin/entity` 渲染或单层 JSON 模型，计划阶段定，以"飞行中可辨认旋转"为验收标准）。

### 2.5 边界场景清单

| 场景 | 行为 |
|---|---|
| 飞行中再次右键 | 手中已无回旋镖（投出即离手），无动作 |
| 回旋镖耐久归零 | 投出落地后不回收，直接损坏消失（`SoundEvents.ITEM_BREAK` 音效+粒子，已验证） |
| 投掷进虚空/世界外 | 10 秒兜底自毁，不掉落（防虚空物品堆积） |
| 吸收的物品很多 | 实体 NBT 列表无上限压力（一次飞行路径有限），回收时满包部分掉落 |
| 命中盔甲架/展示框 | 视为生物路径之外：不伤害（只 LivingEntity），穿过 |
| 水中投掷 | 照常飞（无重力无阻力），不做水体特判 |
| 多人服命中别人 | 正常 2 点伤害（玩具级，PVP 无平衡影响）；归属记投掷者（死亡消息正确） |
| 撞树叶/高草/火把等瞬破方块 | 必碎（不参与 5%），清路手感 |
| 撞黑曜石/基岩等免疫方块 | 永不打碎（tag 判定），必定反弹 |
| 冒险模式投掷 | 不打碎任何方块（防拆家），其余行为正常 |
| `BLOCK_DROPS` 规则关闭 | 方块照碎但不掉落（原版 destroyBlock 语义，不做特判） |
| 穿透后撞到下一个方块 | 重新按 5% 判定（每次碰撞独立摇概率） |
| 飞行中投掷者传送走 | 返程追踪最新位置；跨维度则就地掉落 |

### 2.6 配置

- `boomerangEnabled`（bool，默认 true）
- `boomerangRange`（int，4-24 格，默认 12）
- `boomerangDamage`（int，0-4，默认 2）——设 0 可做纯拾取玩具
- `boomerangBreakBlocks`（bool，默认 true）
- `boomerangBreakChance`（float，0-1，默认 0.05）

### 2.7 实现要点与风险

- 新实体注册进 `ModEntities`（参照 TorchArrowEntity 注册模式）；物品+实体渲染走新物品双文件清单+实体渲染器注册。
- 飞行物理自实现（tick 内位置积分+返程转向），不依赖原版弹射物基类（避免 AbstractArrow 的重力/pickup 语义污染）。
- "每生物每次飞行只伤一次"：实体持 `Set<UUID>`（NBT 序列化）。
- 撞碎方块：新增 tag 文件 `data/quirky/tags/block/boomerang_unbreakable.json`；可碎判定抽纯函数（输入：破坏速度+免疫判定+冒险模式；输出：必碎/摇骰/不可碎），其中破坏速度与冒险模式分支可单测，tag 分支单测环境无数据包数据（项目已知教训）只能手动验证。
- 风险点：
  - 客户端模型旋转渲染 + 实体位置插值（项目教训：视觉位置=实体位置必须一致，用实体的实际位置驱动渲染）。
  - 返程追踪活玩家：`Entity` 引用用 UUID 查找，防内存悬挂。
- 伤害走 `hurtServer`（26.2 服务端伤害 API，参考 docs/26.2-mechanics-notes.md）。

### 2.8 验证

- 单测：飞行步进/返程转向纯数学函数、命中去重集合逻辑、回收槽位选择、碎块可碎判定（破坏速度+冒险模式分支）。
- 手动：桌面客户端投掷手感（弧线/旋转/回收）、拾取、命中一次判定、耐久损坏、满包掉落、**反复投石墙验证约 5% 碎块率、树叶/高草必碎清路、黑曜石/基岩永不碎、穿透后继续飞、破坏开关关闭后只反弹、隔空敲钟/打按钮激活**。

## 3. 公共约定与批内顺序

- 新方块/物品过 `quirky-new-item-checklist`（方块对照现有 `wooden_hopper` 资源结构）；mixin 过 `quirky-mixin-runtime-audit`。
- **批内顺序建议**：绳捆（纯方块，风险低）→ 回旋镖（自定义实体+渲染，批内最重，放最后）。
- 非目标：回旋镖不做附魔（急速/范围）、绳不做横向悬挂/装饰绳。
